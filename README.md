## SVG artwork
Vite generates self-contained `.png.svg` and `.webp.svg` wrappers from original raster artwork before dev/build. These preserve the original pixels and transparency; they are not traced vectors. Existing native SVG files remain unchanged. Run `node scripts/generate-svg-assets.mjs` to generate the files manually.
